# The World Well: Blood of Caro 비공식 한글패치

해당 한글 패치는 제작사의 허가를 받고 제작되었습니다.

《The World Well: Blood of Caro》를 한국어로 즐길 수 있도록 제작한 비공식 한글패치입니다.

게임 내 텍스트를 한국어로 번역하여 적용하는 패치입니다. 번역이나 화면 표시에서 문제가 발견되면 제보를 부탁드립니다.

## 다운로드

이 저장소의 **Releases**에서 한글패치 배포 파일을 내려받아 주세요.

버전별 변경 사항은 각 릴리스 설명에서 확인할 수 있습니다.

> **Assets**에 첨부된 패치 파일을 받아 주세요. `Source code (zip)`과 `Source code (tar.gz)`는 GitHub가 자동으로 제공하는 소스 코드 묶음입니다.

## 지원 환경

- Windows용 Steam판 게임 본편이 별도로 설치되어 있어야 합니다.
- 현재 설치본 기준 게임 빌드: **BuildID 25748264**

게임 업데이트로 파일이 변경되면 기존 패치와 호환되지 않을 수 있습니다. 

해당 이슈를 방지하기 위해 현 패치기는 스크립트 압축 파일을 풀어 영문을 번역 텍스트로 직접 교체합니다.

## 설치 방법

1. 게임을 완전히 종료합니다.
2. Releases에서 받은 한글패치 설치 프로그램을 실행합니다.
3. 게임 설치 경로를 확인하고 패치를 적용합니다. 경로를 직접 지정할 경우, **`BloodofCaro.exe`가 있는 폴더**를 선택해 주세요.
4. 설치 완료 메시지를 확인한 뒤 Steam에서 게임을 실행합니다. 패치기의 게임 실행 버튼을 클릭해도 됩니다.

게임 설치 폴더는 Steam 라이브러리에서 게임을 우클릭한 뒤 **관리 → 로컬 파일 탐색**으로 확인할 수 있습니다.

## 주의사항

- 오탈자, 어색한 표현, 일부 미번역이나 글자 잘림이 남아 있을 수 있습니다. 모든 장면과 진행 분기의 정상 동작을 보장하지는 않습니다.
- 설치 전 중요한 저장 파일을 별도로 백업해 주세요. 게임 폴더의 `savedata`를 따로 보관하는 것을 권장합니다.
- 패치 적용 과정에서 원본 대사 스크립트 백업이 `kr-patch\backups`에 보관됩니다. 원본 복원에 필요한 파일이므로 삭제하거나 수정하지 마세요.
- 게임 업데이트나 Steam 파일 무결성 검사로 한글패치가 해제될 수 있습니다. 이후에는 대응하는 패치 버전을 확인한 뒤 다시 적용해 주세요.
- 패치를 제거하려면 배포 파일의 복원 안내를 따르거나, Steam의 게임 파일 무결성 검사로 원본 파일을 복구해 주세요. `kr-patch` 폴더만 삭제하는 것으로는 패치가 제거되지 않습니다.

## 오류·번역 제보

미번역, 오역, 글자 잘림 또는 진행 중 문제가 발견되면 이 저장소의 **Issues**로 알려 주세요.

해당 화면의 스크린샷, 발생 상황, 게임 빌드와 패치 버전을 함께 남겨주시면 확인에 도움이 됩니다. 

진행 오류나 설치 오류는 재현 방법과 오류 메시지 또는 로그도 함께 첨부해 주세요.
